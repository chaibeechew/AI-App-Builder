# 18-page button contract

All primary surfaces use the same approved control language.

## Primary action families

### Gold primary CTA
Used for final high-confidence actions such as Generate, Build, Launch, Publish and New Project.

- large rounded rectangle
- gold border and gold internal glow
- warm gold gradient
- high-contrast cream/white label
- centered icon + label + optional chevron

### Purple AI CTA
Used for AI-assisted or workflow actions such as Improve, Ask AI, Run Tests, Deploy Ready Platforms and Apply AI changes.

- violet-to-purple gradient
- subtle purple glow
- white label
- medium rounded rectangle

### Glass utility button
Used for Open, Edit, Preview, Manage, View All, Setup, Configure, Connect, Filter and secondary actions.

- transparent navy glass
- pale blue border
- no browser-default appearance
- same radius and vertical rhythm across surfaces

### Selection / tab button
- selected state uses violet fill/glow or gold highlight where the reference specifically shows gold selection
- unselected states remain dark glass

### Toggle
- pill track
- circular white thumb
- purple/green enabled treatment depending on surface semantics

## Interaction states

Every button includes hover, pressed, keyboard focus, disabled and active/selected states. Phone controls maintain touch-action and minimum target sizing.
