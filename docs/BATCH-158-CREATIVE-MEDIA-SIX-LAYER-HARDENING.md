## Scope

This batch completes the shared Creative Media intelligence path for the requested Image 5-layer and Video 6-layer hardening without changing the Malware Defense, App Builder core, LIUI global runtime, Email/SMS or Production Release Control boundaries.

### Image — 5 layers

1. Live-provider execution planning with bounded zero/free candidate admission.
2. Multi-model candidate battle with no automatic metered/premium multiplication.
3. Real-output judge requiring hash-bound measured observation evidence; provider self-reported quality is not accepted as sufficient evidence.
4. Bounded automatic repair/regeneration guidance for prompt adherence, anatomy, text, identity, product, temporal stability and physics failures.
5. Identity / face / product / brand continuity contracts tied to explicit owner-scoped references.

### Video — complete 6 layers

Video receives all five shared layers plus:

6. Cinema + physics intelligence with shot planning, camera intent, motion intent, gravity/inertia/contact constraints, temporal/end-state stability, optional A/V sync requirements and 720p/1080p/1440p/4K finishing targets.

## Cost and safety boundaries

- Zero/free mode keeps premium and metered providers out unless the existing provider policy makes them eligible.
- Multiple paid candidates are blocked unless an explicit multi-candidate-spend permission is supplied.
- Premium remains separately explicit-permission gated by the provider ranking policy.
- Likeness tasks remain blocked without likeness consent.
- No candidate can win only because a provider reports a high quality score.
- Real-output acceptance requires safety, provenance, output validation, signed observation evidence and SHA-256 artifact/observation binding.
- Continuity-sensitive tasks fail closed when required measured continuity signals are missing.
- Video outputs additionally fail the final battle when the cinema/physics evidence gate does not pass.
