This change keeps Big Moon Valley as the LANERIQ AI fresh-home signature while preserving explicit in-session style preview changes.

- The default Cinematic style thumbnail uses the same Big Moon Valley artwork as the homepage.

- A dedicated GitHub Actions contract verifies the preload, final CSS authority, fresh-session behavior, oversized moon, valley river, and Cinematic alignment on every pull request and main push.
