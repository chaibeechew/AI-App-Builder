# LANERIQ 18-page reference map

1. Home / Idea — cinematic future-city landing, intent composer, image/design shortcuts, styles, templates, gold Build CTA.
2. Create Project / Plan — large warm prompt field, target selector, references, smart build options, Project Guard, gold Generate CTA.
3. Build Progress — progress ring, staged build pipeline, AI working status, queued/working/done states.
4. Preview — live product preview, page overview, score, next-step cards, launch CTA.
5. Launch — build success summary, platform target cards, readiness/performance panels, launch CTA.
6. Manage & Grow — project/app stats, user engagement, app list, recent activity, insights.
7. My Projects / Creations — search/filter, project cards with state-specific Open/Edit/Continue/Preview buttons, gold New Project CTA.
8. Templates — search/filter, design previews, industry template grid, Generate with AI CTA.
9. AI Assistant — command composer, command shortcuts, current project, assistant status, suggestions, activity.
10. Automation — workflow cards, toggles, workflow steps, templates, activity, integrations CTA.
11. Analytics & Growth — metrics, trend charts, platform mix, revenue, retention, insights, locations.
12. More & Settings — plan/account/preferences/security/providers/data/domains/help/import/export/danger-zone groups.
13. Project AI Editor — project preview, editor tabs, command center, AI working state, recent changes, Preview/Undo/Compare/Publish controls.
14. Template Detail — template hero, primary actions, metrics, preview phones, feature matrix, AI-ready section, requirements.
15. Workflow Editor — workflow editing state derived from Automation reference system with Save/Test/Activate controls.
16. Database Builder — table tabs, metrics, records preview, schema relationships, database assistant, quick actions, performance chart.
17. AI Testing & Self-Heal — testing dashboard variants consolidated as runtime states/tabs; test pipeline, issue severity, auto-heal, LIUI quality gate, publish readiness.
18. Publish & Deployment Center — platform targets, live preview, build status, domain/hosting, store preparation, deployment history.

Supporting sub-state: Version History & Backups remains accessible inside the project workspace and uses the same advanced-page shell, but does not replace one of the 18 primary page IDs.
