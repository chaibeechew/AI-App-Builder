# LANERIQ Security Android

First installable Android client for LANERIQ Malware Defense / Financial Scam Defense.

Truth boundaries:
- No real scanner evidence => no CLEAN claim.
- APK/sideloaded files remain unverified until cloud + independent scanner evidence is available.
- Raw malware binaries and private file contents are not stored by default.
- No guaranteed theft-prevention claim.

Build: `gradle -p apps/laneriq-security-android assembleDebug`
Artifact: `apps/laneriq-security-android/app/build/outputs/apk/debug/app-debug.apk`
